# O-List Ecommerce Performance Analysis

##  Project Overview
This project provides a comprehensive analysis of the O-List Ecommerce dataset, focusing on sales performance, customer satisfaction, and logistics efficiency. Using Power BI, I transformed raw data into actionable insights to help stakeholders understand business growth and operational bottlenecks.

##  Key Features & Insights
- **Sales Trends:** Analysis of revenue growth and seasonal fluctuations.
- **Logistics Performance:** Evaluation of delivery lead times and carrier reliability across different regions.
- **Customer Feedback:** Correlation analysis between delivery speed and review scores.
- **Product Analysis:** Identification of top-performing categories by revenue and volume.

## 🛠️ Tools Used
- **Power BI:** Data modeling, DAX measures, and Visualization.
- **Power Query:** ETL (Extract, Transform, Load) process to clean and shape the O-List data.
- **Data Source:** O-List Brazilian E-Commerce Dataset.

## 📈 Technical Highlights
- Implemented complex **DAX measures** for Year-over-Year (YoY) growth and rolling averages.
- Developed a **Star Schema** data model for optimized performance.
- Created interactive filters (Slicers) for regional and categorical deep-dives.

## 📁 How to Use
1. Download the `O-List Ecommerce-Analysis.pbix` file from the `/Dashboard/` folder.
2. Open it using **Power BI Desktop**.
3. (Optional) If you want to refresh the data, ensure the source paths are updated to your local directory.
